1. Executive Summary & Purpose

Modern mobile threats targeted at banking infrastructure operate with rapid agility. Fraudulent applications (APKs) distributed via SMS phishing, fake landing pages, and messaging applications exfiltrate SMS OTP codes, inject credit card overlay screens, and execute unauthorized payments behind legitimate banking apps.

Manual reverse engineering of these threat vectors is slow and resource-heavy. GAGMA (Graph-Augmented GenAI Malware Analyst) automates this pipeline entirely. By combining a multi-agent Generative AI system with a high-performance **Neo4j graph database**, GAGMA decompiles APK files, creates structural and call-graph database models, runs risk assessment models, and dispatches real-time, explainable alert payloads to enterprise security networks.

2. Architecture & Pipeline Breakdown

GAGMA has a modular, automated workflow that processes a raw APK file to a completed incident response deployment in seconds:

Step 1: APK Ingestion & Smali/Java Decompilation
The system accepts single APK uploads through a FastAPI interface. In the backend, the decompiler utilizing jadx disassembles smali files and recovers human-readable Java classes, resources, and configuration mappings from AndroidManifest.xml.
Step 2: Neo4j Call-Graph Ingestion
The extracted parameters (method declarations, classes, cross-method call loops, requested permissions, network URLs, and hardcoded C2 IP addresses) are compiled into dynamic relational objects and stored inside a high-speed **Neo4j Malware Knowledge Graph (MKG)**. Nodes map method execution paths while relationships represent [:CALLS], [:REQUESTS_PERMISSION], or [:CONNECTS_TO] connections.
Step 3: Multi-Agent GenAI Threat Assessment Core
Specialized GenAI agents consult the Malware Knowledge Graph to audit method pathways. The agents perform logical code interpretation of obfuscated sections, cross-reference external threat intelligence (VirusTotal & AbuseIPDB APIs), evaluate risk weights, and write clear, natural language explanation summaries regarding the exact malicious behavior found.

3. Key Features & Integrations

3.1. Collapsible CSO Virtual Smartphone (UI Sandbox Showcase)

To provide a highly interactive dashboard experience, a virtual representation of a Chief Security Officer's (CSO) smartphone floats in the bottom-right corner of the GAGMA interface.

  • Sleek Footprint: Collapses by default into a glowing notification bubble to keep the main dashboard unobstructed.
  • Auto-Wake: Instantly expands, vibrates, and triggers a physical notification chime as soon as an APK threat is parsed!
  • Interactive Chat Drawer: Renders a high-fidelity WhatsApp conversation drawer allowing administrative personnel to click "Lock & Quarantine Device" to authorize immediate virtual device lockdowns.

3.2. Automated Incident Response Webhooks (SIEM/MDM Gateway)

GAGMA is fully integrated with enterprise SIEM (Security Information and Event Management) platforms. The gateway dispatches structured JSON webhook payloads containing full method paths, targeted banks, and risk scores to corporate security centers immediately upon threat identification.

3.3. Multi-Channel Redundant Mobile Alerts (WhatsApp & Telegram)

To ensure immediate response under severe incidents, GAGMA implements a dual alerting framework:

  • WhatsApp Gateway (CallMeBot): Dispatches instant alert cards directly to security administrators' personal phones.
  • Telegram Gateway (Backup Bot): Integrates a high-reliability fallback utilizing the official @GagmaAlertsBot, returning instant notification cards with zero delays or rate limits.

  • Graph Database: Neo4j (Graph data mapping, Cypher translation).
  • Reverse Engineering: jadx, Apktool, Androguard.
  • GenAI Core: Google Gemini Pro / OpenAI GPT API orchestrators.
  • Frontend UI: Clean HTML5, Vanilla CSS, Vis.js (Interactive knowledge graph networks), Javascript.
